# Carpride Enhanced

Site de présentation du firmware Carpride Enhanced pour l'écran moto Carpuride W702BS / 702BS Pro
(versions Basique et Premium). Page statique, sans outil de construction : `index.html` + `assets/`.

- Langues : français / anglais (bouton FR · EN, textes anglais dans les attributs `data-en`).
- Lien Premium : constante `PREMIUM_URL` dans le script en bas de `index.html` (vide = « Bientôt disponible »).
- Police Barlow : licence SIL Open Font License (`assets/fonts/OFL.txt`).

Projet indépendant, non affilié à Carpuride ni à BMW.
